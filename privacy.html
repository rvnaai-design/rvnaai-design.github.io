Privacy Policy

Last updated: October 2, 2026

What this app is

RVNA Uploader is a personal tool used only by its owner to upload videos to the owner's own YouTube channel.

What data it accesses

With the owner's permission, the app requests the YouTube scope youtube.upload, which lets it upload videos to the signed-in channel. It does not read viewer data, comments, subscribers, or any other account information.

How data is stored

The app stores only the OAuth credentials needed to upload, kept privately by the owner. No personal data is sold, shared with third parties, or used for advertising.

Google API Services User Data Policy

The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
